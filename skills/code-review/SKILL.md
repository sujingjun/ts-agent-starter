# 可复核的代码审查

先读变更，再读受影响的调用者与测试。优先检查会造成错误结果、越权、数据丢失、重复副作用、资源泄漏和兼容性破坏的问题。

每条发现包含严重程度、文件与行范围、触发条件、可验证的影响、建议修复及回归测试。不把个人风格偏好写成缺陷；信息不足时写“待验证”并说明所需证据。

需要审查格式时读取 `references/review-contract.md`。使用测试工具前确认其执行范围和授权。未运行测试就明确写未运行；不得把建议的测试描述为已经通过。修改文件必须调用受权限控制的写工具，技能不能绕过审批。
