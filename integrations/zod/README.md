# 将工具约束接到 Zod

核心为了让课程能够离线运行，提供严格、明确的 JSON Schema 子集验证器；不是完整 JSON Schema 实现。它拒绝 `$ref`、`oneOf`、`pattern` 等尚未支持的关键字，不会静默忽略。

MCP 示例使用 Zod。业务采用 Zod 时应在边界完成 `safeParse`，再把经过验证的 JSON 传给 Tool。复杂 Schema 不应先删去校验关键字再注册；应实现独立 Tool 验证适配器并补契约测试。

选择不是“自研校验器比 Zod 更好”，而是把能离线验证的教学核心与外部集成分开。本次没有把 Zod 当作已经通过验证的核心依赖。
