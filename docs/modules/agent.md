# 工具型 Agent

## 职责与入口

源码：`integrations/langchain/agent.ts`。

以 createAgent 组织模型调用与工具执行，串入完整轮次上下文裁剪、模型次数上限、工具次数上限以及笔记写入审批。

## 体验与验收

在体验台选择工具型 Agent，输入「计算 (2+3)*4」，查看工具开始、结束及流式文本。继续同一对话问「我刚才问了什么」。

## 限制与扩展约束

模型请求失败、参数不匹配、次数用尽都会显式失败。扩展工具应在 makeTools 注册，不另写包在 createAgent 外面的无限循环。

涉及外部依赖的测试结果见 [验证记录](../../VALIDATION.md)。模块清单见 [模块索引](../MODULES.md)。
