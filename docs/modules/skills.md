# 技能按需加载

## 职责与入口

源码：`src/core/skills.ts`。

SkillCatalog 加载元数据，执行时按需读取正文。框架提供 load_skill 工具；体验台也可显式选择技能，把相关正文加入该次用户任务。

## 体验与验收

选择研究报告技能，再提交「MCP 工具」；检查运行的 skill 标识。技能脚本有独立命令，不因出现于 SKILL.md 就获得任意 shell 权限。

## 限制与扩展约束

原生支持的 YAML 子集与路径检查见源码，不假设兼容所有厂商扩展。技能不是权限边界，不能关闭人工审批。

涉及外部依赖的测试结果见 [验证记录](../../VALIDATION.md)。模块清单见 [模块索引](../MODULES.md)。
