# 长期笔记

## 职责与入口

源码：`src/features/notes.ts`。

文件按租户哈希分目录；内容哈希作为笔记 ID，相同内容保存去重。不同于会话 checkpoint，笔记只保存用户明确批准的事实。

## 体验与验收

输入「记住：我使用 TypeScript」，先拒绝一次，再新建任务批准。新会话输入「读取笔记」。

## 限制与扩展约束

默认最多列出100条；不自动把所有聊天沉淀长期记忆。当前没有笔记编辑/删除界面，属于后续数据治理扩展。

涉及外部依赖的测试结果见 [验证记录](../../VALIDATION.md)。模块清单见 [模块索引](../MODULES.md)。
