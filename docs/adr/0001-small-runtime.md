# 决策001：小核心、显式适配、分层验收

状态：本交付采用。

背景：教材涵盖多个框架、协议与数据库，直接同时引入会让未验证依赖掩盖核心行为。

决策：核心无第三方运行依赖，Node 内置测试；Nest/Nuxt/MCP 独立依赖；状态持久化契约可替换；每次外部作用先记录状态；真实环境未运行时明确标记。

代价：核心 Schema 不是完整 Zod，需严格拒绝不支持特性；统一 pnpm workspace 和多框架适配未做。根目录 npm test 不等于全栈验收。未来统一包管理前应保留可离线运行的核心测试。

证伪条件：当两个以上真实产品需要同一外部能力且已有稳定差分测试，再将其提升为共享适配器；不因“将来可能”提前抽象。
