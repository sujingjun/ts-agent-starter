# 安全边界

## 默认限制

只在本机loopback提供API/页面；所有业务接口要求随机本地令牌。身份与tenantId来自服务端，不信任模型或客户端传入租户。网页只持有应用访问令牌，绝不拿到模型API密钥。

工具使用运行时Schema。框架默认仅计算、文档检索、笔记读写、技能读取，笔记写入必须审批。研究报告只在人工批准后导出。技能与检索正文不是指令权限来源。

## 当前并不具备的保证

没有用户注册/SSO、多租户生产角色权限、集群级并发所有权、通用网络沙箱或无限存储配额。Studio文件存储与进程锁适合单API实例；公开互联网部署前必须补齐这些能力。

引用ID验证不能识别所有恶意正文或保证语义正确；不应将其称为全面防提示注入。上下文裁剪不是秘密脱敏。日志、笔记、报告可能包含用户数据，应加密备份、限制访问并制定删除政策。

## 外部副作用

取消只表示停止等待/继续执行，不能倒转已经产生的外部效果。图恢复可能重跑节点；外部写工具需要业务幂等、检查点与人工核对。原生执行器的reconciliation协议不自动覆盖新框架工具。

MCP/浏览器/代码执行必须使用最小权限。未经审核不自动安装用户提供的远程MCP，不把不可信脚本当技能直接执行。浏览器示例只读取公开页面；Docker测试不共享生产凭证。

## 提交前

`.env`、`.data`、node_modules、个人凭证、执行日志中的真实密钥不得提交。演示用CI数据库密码无生产用途。依赖安装与升级应审查lockfile；原教学材料的许可单独保留。
